##  My Approach

For each project, I aim to go beyond simply completing the technical exercise.

My approach is generally structured around:

**Business Problem → Data → Analysis → Insights → Recommendation**

I focus on understanding:

1. **What is the business problem?**
2. **What does the data tell us?**
3. **What are the key drivers and patterns?**
4. **What operational risks or opportunities exist?**
5. **What actions could improve supply chain performance?**

This reflects my broader interest in combining **supply chain knowledge with data-driven decision-making**.
